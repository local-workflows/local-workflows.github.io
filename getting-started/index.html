Getting started

The manual. One page per feature, and each page is the whole feature: a build-it-yourself walkthrough first, then every key, every rule, and a complete example — for a person reading top to bottom and for a model fetching one page to author a file.

In order:

  1. Install — the extension, and the one prerequisite that is not obvious.
  2. Agent SDKs — GHCP, the default provider for AI tasks and specs, and what an agent session is given. claude is the other; everything that is not an AI task works without either.
  3. Tasks — tasks.yml, a library of commands. Start here: values, templating and anchors are covered once, on this page, for both formats.
  4. Workflows — one pipeline: stages, parallel jobs, an AI draft, a human gate.
  5. Variables — every built-in variable on one page: the anchors, params, vars, env and run.context, and the one resolution order.
  6. Spec-driven development — requirements, design, plan, implementation, with a decision between each. The shipped styles, their exact prompts, and writing your own.
  7. Plugins — the last, smallest thing that executes. The six that ship, and writing your own in plain JavaScript.
  8. package.json scripts — your existing npm scripts, listed beside everything else.
  9. settings.json — the engine’s one configuration file.
  10. Agent Client Protocol — adding an agent this build has no dedicated provider for, like Kiro, as provider: on an ai@1 task.
  11. Workspaces — where “here” is: folder, workspace and profile scopes, and what changes when you open a .code-workspace.
