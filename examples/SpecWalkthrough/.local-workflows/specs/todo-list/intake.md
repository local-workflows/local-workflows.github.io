# todo-list

## What is being asked

A todo list you can use from the command line.

Add an item, mark it done, mark it open again, delete it, and see the
list. Being able to see only what is still open matters more than
anything else on the list - that is the whole reason for looking.

It has to remember what is on the list between runs. Closing the
terminal and opening it again should show the same list.

It is one person's list on one machine. No accounts, no server, no
sharing, no due dates, no priorities, no tags.
